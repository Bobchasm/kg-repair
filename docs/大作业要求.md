# 知识图谱结课大作业

### 作业提交

压缩包命名方式：项目名称命名

- 小组个成员分工明细

- 大作业独创声明

- 大作业文档

- 源代码

- 4-5min视频讲解任务

### 要求

**(1) 题目**

利用以下网盘中任意文档构建或抽取出一个完整的知识图谱，最多2人一组

[天大云盘](https://pan.tju.edu.cn/anyshare/en-us/link/AA641F97908DBB4174A7EBF405F6378F2F/DC217994F2D84F2B81E36B7DB84E67D2/CA6A51510EAB438DB09921A54A71D2ED/527B68BD0993482891FD260942C01253?_tb=none)  提取码：ZtVn

**(2) 要求**

各个文档的内容和格式参考附件，人工构建概念不少于500，关系不少于1000，一些项目关系较少时实体应该更加全面，自动抽取要求提供算法源代码(可以基于LLM，但不允许只用LLM)，并标注其中至少200个概念和400个以上的关系进行算法评估，2人1组的要求构建一个知识图谱应用

**(3) 评分**

大作业教师评分：大作业文档40分(即技术报告，评价依据：文档规范性，完整性，创新性)，源代码40分(考核参考依据：代码规范性，功能完整性等)。视频20分(考核参考依据：讲解清晰程度、展示成果的全面性，成果质量等)
